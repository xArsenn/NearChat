# NearChat 中文说明

[返回双语首页](README.md) · [English](README.en.md)

NearChat 是一个无需账号、无需云服务器的开源局域网聊天与文件协作工具。

创建房间的电脑会在局域网中临时充当主机。其他电脑可以自动发现房间，手机扫描二维码后则可以直接在浏览器里加入，无需下载或安装 NearChat。退出 NearChat 后，临时网页服务和所有连接会立即停止；只关闭窗口则会继续在系统托盘运行。

## 当前功能

- 中文、英文界面一键切换，并记住语言选择
- 手机扫描二维码免安装加入
- 手机浏览器发送和接收消息、图片及文件
- 自动发现同一局域网内的房间
- 房间 ID 与口令自动查找主机，无需填写地址和端口
- 地址和端口仅作为高级设置备用
- 多人局域网聊天与在线成员列表
- 设备指纹与本地可信设备标记
- 陌生设备发送文件前先确认，可信设备可自动接收
- 关闭窗口后在系统托盘继续运行，不中断房间和传输
- 可选开机自动启动，以及消息、文件请求和完成系统通知
- 为成员设置仅自己可见的本地备注，聊天与文件显示备注名
- 加密共享剪贴板：发送文字或剪贴板图片，接收后可一键复制
- 文件拖入聊天窗口即可加密发送，一次最多处理 20 个文件
- 文件收件箱集中查看发送者备注、校验状态和保存入口
- 桌面端采用流式落盘，不再受原来的 50 MB 应用限制，也不会把整个文件装入内存
- 发送整个文件夹并保留多层目录结构，收到的文件自动保存到“下载/NearChat”
- 实时传输进度、速度、预计剩余时间、发送背压与失败重试
- SHA-256 文件完整性校验与送达确认
- AES-256-GCM 应用层加密
- Windows 安装包与软件内自动更新

## 推荐连接方式

1. 所有设备连接同一个 Wi-Fi、手机热点或有线局域网。
2. 一台电脑打开 NearChat 并创建房间。
3. 其他电脑选择“扫描附近房间”，选中房间并输入口令。
4. 手机直接扫描房主界面的二维码，在浏览器中输入名称并加入。
5. 点击顶部剪贴板按钮可发送文字或截图；文件可以直接拖进聊天区域，整个文件夹可通过文件夹按钮选择。
6. 如果自动发现失败，可以读取一键邀请；地址和端口仅在高级设置中使用。
7. Windows 首次询问网络权限时，请允许 NearChat 访问专用网络。
8. 在设置中可开启开机启动；要彻底退出，请使用系统托盘菜单中的“退出”。

共享剪贴板只会在用户点击时读取，不会在后台自动同步密码、验证码或其他敏感内容。

桌面端之间可以传输大型文件。手机免安装网页端目前单文件仍限制为 50 MB；当房间内同时存在桌面端和手机访客时，大于 50 MB 的文件只发送给桌面端，以保护手机浏览器内存。

## 本地开发

需要 Node.js 20 或更新版本：

```bash
npm install
npm run desktop
```

构建网页资源：`npm run build`

生成 Windows 正式安装包：`npm run package:release`

## 自动更新与发布

正式版使用 Windows NSIS 安装包。用户可在软件中点击“检查软件更新”，发现新版本后直接下载并重启安装。发布时更新版本号、提交代码并推送同版本标签，GitHub Actions 会自动创建安装包和 Release。

## 安全说明

消息和文件使用 AES-256-GCM 加密，密钥通过 PBKDF2 从随机房间口令派生。设备指纹和可信标记用于帮助识别再次出现的设备，但不等同于证书级身份认证。

NearChat 尚未经过独立安全审计，不建议用于传输高敏感信息。聊天文字保存在本机，目前尚未进行本地磁盘加密。
